# 🏛️ Professional Vocational Training Center Management System
## Full-Stack React Application — Government-Grade UI

---

## 🎯 PROJECT OVERVIEW

Build a complete, professional, government-style Student Management System (SMS) for a Moroccan Vocational Training Center (Centre de Formation Professionnelle). The system must look and feel like an official government portal — clean, formal, trustworthy, and fully RTL-compatible.

---

## 🛠️ TECH STACK

- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS + custom CSS for RTL support
- **Routing:** React Router v6
- **State Management:** Zustand or Context API
- **Data Persistence:** localStorage + JSON file import/export
- **PDF Generation:** jsPDF + jsPDF-AutoTable
- **Excel Generation & Import:** SheetJS (xlsx)
- **Icons:** Lucide React
- **Internationalization (i18n):** i18next + react-i18next
- **Date Picker:** react-datepicker
- **UI Components:** Headless UI or Radix UI
- **Print/Export:** html2canvas + jsPDF

---

## 🌐 LANGUAGES (i18n)

The system must support **3 languages** switchable from the navbar:
- 🇲🇦 **العربية (AR)** — RTL, default language
- 🇫🇷 **Français (FR)** — LTR
- 🇬🇧 **English (EN)** — LTR

All UI text, labels, buttons, table headers, alerts, and messages must be fully translated in all 3 languages. Store translations in `/locales/ar.json`, `/locales/fr.json`, `/locales/en.json`.

---

## 🎨 DESIGN SYSTEM — Government Style

- **Color Palette:** Deep green (`#1a5c38`) as primary, white, light gray, gold accents
- **Header:** Government logo placeholder (left), Center name (center), language switcher + user info (right)
- **Typography:** Cairo font (Arabic), Inter (Latin)
- **Layout:** Sidebar navigation (collapsible) + main content area
- **RTL/LTR:** Automatically switch layout direction based on selected language
- **Tables:** Zebra-striped, sortable, with sticky headers
- **Responsive:** Desktop-first but mobile-friendly
- **Branding:** Add Moroccan government-style header with emblem placeholder
